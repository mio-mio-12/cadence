Cast model/animation viewer and map loader

cast exports must be done using OpenGL normal maps, not Saluki's default/DirectX. Make sure to change this in your exporter's settings.

supported games:

- cod4
- mw2 (2009) (untested)
- mw3 (2011)
- bo1
- bo2
- ghosts
- aw
- iw
- mwr
- codm
- cs2
- pointblank
